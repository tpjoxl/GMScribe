# 格式跟 glossary.txt 一樣:「錯的寫法 | 另一種錯的寫法 => 正確寫法」,含英文的不分大小寫、前後不能緊接著英數字。
# 收錄原則:左邊的寫法在任何情境下都不會是正確用詞,換掉不會誤判。只出現在特定公司/會議的詞(同事名字、
# 內部專案名)請放在自己的 glossary.txt;一般詞彙也可能被聽錯的(例如「前段」可能是「前段時間」)不收。
