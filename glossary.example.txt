# 常被聽錯的固定詞彙對照表(範本)。使用方式:複製一份成 glossary.txt 再自己編輯
#   cp glossary.example.txt glossary.txt
# glossary.txt 不會進版控(裡面通常是同事名字、公司內部用語)。沒有這個檔案就不做替換。
#
# 格式:每行「聽錯的寫法 | 另一種聽錯的寫法 => 正確寫法」,# 開頭是註解。
# 只放每次開會都會出現的東西(同事名字、常用工作詞),不放當次會議的主題詞。
# 改完存檔就生效,不用重啟伺服器。英文比對不分大小寫、只比對完整單字;簡體/繁體寫法會自動一起比對。
# 注意:左邊的詞會在逐字稿裡「全部」被換掉,一般用語(例如 cloud、「像你」)不要放進來。

# 範例(拿掉開頭的 # 就會生效):
# 王曉明 | 王小名 => 王小明
# 吉拉 | Gira => Jira
# 飛哥馬 | Fig Ma => Figma
# 尾芽 | 偉牙 => 尾牙
